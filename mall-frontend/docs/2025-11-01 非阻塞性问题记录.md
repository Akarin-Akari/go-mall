## 📋 问题分类

### 控制台警告类

#### 问题 1: Next.js Metadata Viewport 警告

**严重程度**：⚠️ **低**（非阻塞）  
**影响范围**：Next.js 配置  
**问题描述**：
- 控制台警告：`Unsupported metadata viewport is configured in metadata export`
- Next.js 15 要求将 viewport 配置从 metadata 迁移到独立的 viewport export

**错误信息**：
```
⚠ Unsupported metadata viewport is configured in metadata export in /. 
Please move it to viewport export instead.
Read more: https://nextjs.org/docs/app/api-reference/functions/generate-viewport
```

**复现步骤**：
1. 访问任何页面（首页、登录页等）
2. 打开浏览器开发者工具
3. 查看控制台警告

**当前影响**：
- 功能正常运行
- 仅控制台警告，不影响用户体验

**建议修复方案**：
```typescript
// 当前方式（layout.tsx）
export const metadata = {
  viewport: {
    width: 'device-width',
    initialScale: 1,
  },
};

// 应改为（layout.tsx）
export const viewport = {
  width: 'device-width',
  initialScale: 1,
};
```

**修复优先级**：P1（近期执行）  
**预估工作量**：0.1 人日

#### 问题 2: Ant Design React 19 兼容性警告

**严重程度**：⚠️ **低**（非阻塞）  
**影响范围**：Ant Design 组件  
**问题描述**：
- 控制台警告：`antd v5 support React is 16 ~ 18`
- 当前使用 React 19.1.0，Ant Design 5.27.1 不完全支持

**错误信息**：
```
Warning: [antd: compatible] antd v5 support React is 16 ~ 18. 
see https://u.ant.design/v5-for-19 for compatible.
```

**复现步骤**：
1. 访问任何包含 Ant Design 组件的页面
2. 打开浏览器开发者工具
3. 查看控制台警告

**当前影响**：
- 功能正常运行
- UI组件正常显示
- 可能存在潜在的兼容性问题

**建议修复方案**：
1. 等待 Ant Design 官方发布 React 19 兼容版本
2. 或降级 React 到 18.x（不推荐）
3. 关注官方兼容性指南：https://u.ant.design/v5-for-19

**修复优先级**：P2（后续优化）  
**预估工作量**：待定（取决于官方更新）

#### 问题 3: Ant Design 弃用API警告

**严重程度**：⚠️ **低**（非阻塞）  
**影响范围**：Ant Design 组件使用  
**问题描述**：
- 多个组件使用了已弃用的API属性
- 包括：Spin `tip`、Card `bodyStyle`、Breadcrumb 等

**错误信息示例**：
```
Warning: [antd: Spin] `tip` only work in nest or fullscreen pattern.
Warning: [antd: Card] `bodyStyle` is deprecated. Please use `styles.body` instead.
```

**复现步骤**：
1. 访问包含相关组件的页面
2. 打开浏览器开发者工具
3. 查看控制台警告

**当前影响**：
- 功能正常运行
- 仅控制台警告，不影响用户体验

**建议修复方案**：
```typescript
// 当前方式
<Card bodyStyle={{ padding: 0 }}>...</Card>

// 应改为
<Card styles={{ body: { padding: 0 } }}>...</Card>
```

**修复优先级**：P1（近期执行）  
**预估工作量**：0.5 人日

### 前端错误类

#### 问题 4: Frontend Error [object Object]

**严重程度**：⚠️ **中**（非阻塞，需调查）  
**影响范围**：首页、结算页  
**问题描述**：
- 控制台出现 `[Frontend Error] [object Object]` 错误
- 错误信息不够详细，难以定位具体问题

**错误信息**：
```
[Frontend Error] [object Object]
```

**复现步骤**：
1. 访问首页或结算页
2. 打开浏览器开发者工具
3. 查看控制台错误

**当前影响**：
- 页面功能正常
- 可能隐藏了实际的错误信息
- 影响错误调试和问题定位

**建议修复方案**：
1. 检查错误边界组件（ErrorBoundary）
2. 检查错误处理代码中的 `console.error` 或 `console.log`
3. 使用 `JSON.stringify()` 或 `console.error()` 输出详细错误信息
4. 添加错误堆栈跟踪

**需要调查的位置**：
- `src/components/common/ErrorBoundary.tsx`
- 首页相关组件
- 结算页相关组件

**修复优先级**：P1（近期执行）  
**预估工作量**：0.3 人日
