## 📊 数据模型分析

### User 模块 (37个字段)
```go
type User struct {
    // 基础信息
    ID, Username, Email, Password, Nickname, Avatar, Phone
    
    // 角色权限
    Role     // super_admin, admin, user, merchant, customer
    Status   // active, inactive, locked, banned
    
    // 个人资料
    RealName, Gender, Birthday, Bio, Location, Website
    
    // 验证状态
    EmailVerified, PhoneVerified, EmailVerifiedAt, PhoneVerifiedAt
    
    // 安全信息
    LastLoginAt, LastLoginIP, LoginAttempts, LockedUntil
    PasswordChangedAt, TwoFactorEnabled, TwoFactorSecret
    
    // 统计数据
    Balance, LoginCount, PostCount, FollowerCount, FollowingCount
    
    // 时间戳
    CreatedAt, UpdatedAt, DeletedAt
    
    // 关联
    Files, LoginLogs, Profile
}
```

### Product 模块 (40+字段)
- **Product**: 商品主表，支持 SKU、多图、属性
- **Category**: 商品分类（支持多级）
- **Brand**: 品牌
- **ProductImage**: 商品图片
- **ProductAttr**: 商品属性
- **ProductSKU**: 库存单位
- **ProductReview**: 商品评价

### Order 模块 (60+字段)
- **Order**: 订单主表，完整生命周期
- **OrderItem**: 订单商品项
- **OrderStatusLog**: 状态变更日志
- **OrderPayment**: 订单支付记录
- **OrderShipment**: 订单物流
- **OrderAfterSale**: 售后服务
- 状态: pending → paid → shipped → delivered → received → completed

### Cart 模块 (20+字段)
- **Cart**: 购物车主表
- **CartItem**: 购物车商品项
- **CartSummary**: 购物车统计
- **CartMergeLog**: 购物车合并日志

### Payment 模块 (30+字段)
- **Payment**: 支付记录
- **PaymentLog**: 支付日志
- **PaymentRefund**: 退款记录
- 支持: 支付宝、微信支付

## 🚀 快速启动

### 后端启动
```bash
cd mall-go

# 安装依赖
go mod tidy

# 配置数据库和Redis (configs/config.yaml)

# 启动服务
go run cmd/server/main.go
```

### 前端启动
```bash
cd mall-frontend

# 安装依赖
npm install

# 开发模式
npm run dev

# 生产构建
npm run build
```

### Docker 启动
```bash
cd mall-go
docker-compose up -d
```
